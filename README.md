# AI Text Rewriter

## Project Description
AI Text Rewriter is a web application that uses Generative AI to rewrite text in different writing tones while preserving the original meaning.

## Features
- AI-powered text rewriting
- Four writing tones: Professional, Formal, Friendly, and Simple
- Copy rewritten text
- Input validation
- Responsible AI privacy reminder

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Groq API

## How to Run Locally
1. Clone this repository.
2. Install dependencies:
   `npm install`
3. Create a `.env` file in the project folder.
4. Add your Groq API key:
   `GROQ_API_KEY=your_api_key_here`
5. Start the server:
   `npm start`
6. Open `http://localhost:3000` in your browser.

## Responsible AI
Users should avoid entering confidential information and review AI-generated content before using it.
